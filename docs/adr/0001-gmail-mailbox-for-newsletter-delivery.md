# Gmail 받은편지함 단위로 발송과 해지 적용

개인 Gmail은 점 위치가 다른 주소도 같은 받은편지함으로 전달된다. 기존 주소를 병합하면 가입 이력과 해지 링크를 잃을 수 있으므로 각 가입 기록을 보존하고, 발송 때는 받은편지함마다 최신 활성 동의를 사용하며 더 최근에 해지했거나 순서를 확인할 수 없으면 제외한다. 해지 요청은 그 주소와 연결된 받은편지함에 적용해 다른 점 표기로 발송이 계속되는 일을 막는다.

관리자의 발송 제외와 취소도 받은편지함 단위로 적용하며, 취소할 때는 각 주소의 이전 상태를 복원한다. 재가입하면 해당 받은편지함의 이전 해지 링크가 모두 만료되어 어느 주소의 예전 메일을 열었는지에 관계없이 새 구독에 같은 기준이 적용된다.
