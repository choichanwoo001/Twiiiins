## 🇬🇧 English

TWIIIINS is an official website for a contemporary music and performance duo. The site presents projects, concerts, media, downloadable press materials, and contact information through a custom-built full-stack web application.

**Live site:** https://twiiiins.com

### Overview

This project was built as a production website with an admin workflow for keeping content up to date without editing code. It includes public-facing pages for performances and media, plus an internal admin interface for managing concerts, projects, music, equipment, downloads, and contact entries.

### Key Features

- Responsive public website for desktop and mobile
- Project detail pages with image galleries and structured project metadata
- Concert/event listing with upcoming and past event management
- Media sections for videos, photos, music, equipment, and downloadable files
- Admin content management UI for CRUD operations
- Image upload pipeline with generated responsive variants
- PDF and image upload support for downloadable contact/press files

### Tech Stack

- **Frontend:** Vue 3, Vite, Pinia, Vue Router, Axios
- **Backend:** Spring Boot 3, Java 17, Spring Data JPA, Spring Security
- **Database:** MySQL
- **Media:** Local file storage, responsive image variants, PDF/image downloads

## 🇰🇷 한국어

TWIIIINS는 현대 음악 및 퍼포먼스 듀오의 공식 웹사이트입니다. 프로젝트, 콘서트, 미디어, 다운로드 가능한 홍보 자료, 연락처 정보를 풀스택 웹 애플리케이션으로 제공합니다.

**라이브 사이트:** https://twiiiins.com

### 개요

이 프로젝트는 코드 수정 없이 콘텐츠를 최신 상태로 유지할 수 있는 어드민 워크플로우를 포함한 프로덕션 웹사이트입니다. 공연 및 미디어를 위한 퍼블릭 페이지와 함께, 콘서트·프로젝트·음악·장비·다운로드·연락처 항목을 관리하는 내부 어드민 인터페이스를 포함합니다.

### 주요 기능

- 데스크탑 및 모바일 반응형 퍼블릭 웹사이트
- 이미지 갤러리 및 구조화된 메타데이터를 포함한 프로젝트 상세 페이지
- 예정된 공연 및 지난 공연 관리 기능이 있는 콘서트/이벤트 목록
- 영상, 사진, 음악, 장비, 다운로드 파일을 위한 미디어 섹션
- CRUD 기능을 갖춘 어드민 콘텐츠 관리 UI
- 반응형 이미지 변환 파이프라인을 포함한 이미지 업로드
- 다운로드 가능한 연락처/홍보용 파일을 위한 PDF 및 이미지 업로드 지원

### 기술 스택

- **프론트엔드:** Vue 3, Vite, Pinia, Vue Router, Axios
- **백엔드:** Spring Boot 3, Java 17, Spring Data JPA, Spring Security
- **데이터베이스:** MySQL
- **미디어:** 로컬 파일 스토리지, 반응형 이미지 변환, PDF/이미지 다운로드
